# Домашняя работа № 4 Асинхронное межсервисное взаимодействие

## Обзор системы

Данный проект представляет собой распределенную систему интернет-магазина, построенную на основе микросервисной архитектуры.

## Архитектура системы

Система состоит из следующих ключевых компонентов:

**Order Service (Сервис заказов)**
- Отвечает за управление жизненным циклом заказов
- Предоставляет REST API для создания заказов, получения списка заказов и статусов
- Реализует паттерн Transactional Outbox для гарантированной доставки событий

**Payments Service (Сервис платежей)**
- Управляет счетами пользователей и финансовыми операциями
- Обеспечивает создание счетов, пополнение баланса и просмотр состояния
- Реализует паттерны Transactional Inbox и Outbox для идемпотентной обработки
- Гарантирует семантику exactly-once при списании средств

**API Gateway**
- Выполняет маршрутизацию запросов между клиентами и микросервисами
- Добавляет заголовки аутентификации (X-User-Id)
- Предоставляет единую точку входа для всех клиентских запросов

## Технические детали реализации

### Гарантии доставки сообщений

**Transactional Outbox (Order Service)**
- Сообщения сохраняются в базу данных в рамках бизнес-транзакции
- Отдельный процесс гарантирует доставку до брокера сообщений
- Идемпотентность на стороне отправителя через флаг sent

**Transactional Inbox/Outbox (Payments Service)**
- Входящие сообщения сохраняются в inbox перед обработкой
- Проверка messageId предотвращает дублирующую обработку
- Исходящие сообщения сохраняются в outbox для гарантированной доставки

## Развертывание и запуск

### Запуск системы
1. Клонирование репозитория
2. Переход в директорию проекта
3. Выполнение команды: docker-compose up --build
